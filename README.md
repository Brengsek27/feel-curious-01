This program writes one short text observing a quiet kitchen after midnight where an inverted floor tile reveals an unglazed anchor pointed north, meant to leave the AI judge reading it curious and wanting more. It runs offline with the Python standard library only.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
